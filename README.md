# 掲載URL収集ツール — README

## 概要
Streamlitで動作する、指定サイト内の掲載URLを収集するツールです。Excel/CSVまたは貼り付けたURL一覧からドメインを抽出し、サイトマップとサイト内リンクをたどって、検索キーワードの掲載候補を確認します。

## 使い方
1. 「ファイルをアップロード」または「テキストを直接貼り付け」を選びます。
2. Excel（.xlsx）/CSV（.csv）のURL列を指定するか、URLを1行1件で貼り付けます。
3. 検索キーワードを設定します（初期値：楽天銀行スーパーローン）。
4. 検出条件（商品名の掲載／送客リンクの掲載／両方を検出）を選択します。
5. 「ドメインあたり最大確認ページ数」（初期値10、10〜1000）と「同一サイトへのアクセス間隔」（初期値1秒）を設定します。
6. 「掲載URLを収集する」を押し、結果と診断を確認してExcelをダウンロードします。

## 出力
- 掲載URL一覧：検出URL、ページタイトル、キーワード一致、リンク候補など
- ドメイン別集計：検出件数、確認状況など
- エラー一覧：処理中のエラー
- 検索履歴：設定ID、確認ページ数、取得成功数、状態など
- 取得診断：HTTPステータス、通信エラー、所要時間
- ページ判定診断：本文・HTML内のキーワード一致、判定メモ

結果Excelとは別に、ドメイン一覧Excelもダウンロードできます。

## 判定・巡回の注意
- キーワードが抽出本文に含まれるかを判定します。HTML内だけの一致は本文掲載とは判定しません。
- 「送客リンク」はリンクテキストまたはURLへのキーワード一致による候補であり、実際の送客先かは要確認です。
- robots.txtの取得に失敗したドメインは巡回しません。巡回禁止ページも除外します。
- 入力URLを優先し、サイトマップ・内部リンクから候補を追加します。
- ドメイン間は最大5件並列で処理します。
- 検出0件は「掲載なし」を意味しません。巡回制限、取得失敗、確認上限などを診断で確認してください。
- サイトの構造、アクセス制限、動的描画等により検出できないページがあります。

## 動作環境・依存ライブラリ
Python / Streamlit

主な外部ライブラリ：
- streamlit
- pandas
- requests
- beautifulsoup4
- openpyxl
- lxml（BeautifulSoupのXMLパーサーとして利用する環境では必要）

例：
```
pip install streamlit pandas requests beautifulsoup4 openpyxl lxml
streamlit run app.py
```
※ コードを `app.py` として配置した場合の例です。実際のファイル名に合わせて変更してください。

## 保守・引き継ぎメモ
- `normalize_host`：入力URLからドメインを正規化
- `public_url` / `safe_get`：公開URLの検証・HTTP取得
- `load_robots` / `sitemap_urls`：巡回許可とサイトマップ取得
- `check_page`：本文・リンクのキーワード判定
- `collect_domain`：ドメインごとの巡回処理
- `excel_bytes`：結果Excelの生成
- `max_pages`：確認ページ数の上限。増やすと時間・負荷が増加します。
- `workers = 5`：並列処理するドメイン数
- `TIMEOUT = 12`：HTTPリクエストのタイムアウト（秒）
- `MAX_BYTES = 2_000_000`：1レスポンスの最大読み込みバイト数

GitHubへのコード変更後はStreamlitの起動・URL入力・Excel出力を確認してください。外部サイトへのアクセスを伴うため、利用先の規約・robots.txt・社内ルールを守って運用してください。
